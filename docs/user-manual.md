# AutoWake 사용자/운영자 메뉴얼

## 1. 프로그램 개요

AutoWake는 공용 PC에서 지정 사이트를 항상 접근 가능 상태로 유지하고,
유휴 시간에는 세이버를 띄우며, 필요 시 안내 팝업을 사용자에게 표시하는 운영 도구입니다.

주요 대상:
- 도서관 검색 전용 PC
- 키오스크형 안내 단말
- 관리자가 원격/현장으로 정책 적용하는 공유 단말

---

## 2. 최초 실행

1. `autowake_beta.exe`를 실행합니다.
2. 트레이 아이콘이 생성되고 기본 워커가 자동 시작됩니다.
3. 설정창에서 URL/세이버/오디오/안내 팝업 정책을 조정합니다.

> 기본 저장 경로는 `C:\AutoWake`입니다.

---

## 3. 화면/메뉴 구성

실제 UI는 탭 중심 구성입니다.

- 대상(Target): 기본 접속 URL 목록, 창 모드, 재실행 정책
- 오디오(Audio): YouTube URL 목록, 실행 모드(Chrome/PWA), 반복 정책
- 세이버(Saver): 유휴 시간 임계값, 표시 모드, 이미지
- 안내(Notice): 제목/본문/푸터/폰트/정렬/이미지/사이즈/반복
- 테마(Theme): 강조색/테마

트레이 메뉴:
- 시작
- 중지
- 설정 열기
- 종료

---

## 4. 운영 시나리오별 설정

## 시나리오 A: 대상 사이트만 유지

- 오디오 비활성화
- 대상 활성화
- 반복 모드 `repeat`
- 재실행 쿨다운 10분 내외 권장

## 시나리오 B: 대상 + 백그라운드 음악

- 오디오 활성화
- 실행 모드: 우선 Chrome (문제 없으면 PWA 전환)
- 오디오 창 모드: 최소화
- 재실행 쿨다운: 180초 내외

## 시나리오 C: 강한 안내 정책

- Notice 활성화
- 반복 표시 활성화(예: 30분)
- 닫기 가능 여부/문구를 운영 정책에 맞게 설정

---

## 5. 상세 기능 설명

## 5.1 대상 URL 자동 실행

- URL 리스트 중 임의/정책 순서로 브라우저 실행
- 브라우저가 닫히거나 창이 사라지면 재실행
- 워커별 전용 Chrome 프로필 사용으로 충돌 감소

## 5.2 오디오 실행(Chrome/PWA)

- Chrome 모드: 가장 호환성이 높음
- PWA 모드: 설치된 YouTube 앱 App ID 탐지 후 실행
- 실패 시 Chrome 모드로 자동 대체될 수 있음

## 5.3 세이버

- 키보드/마우스 유휴 시간 기반 표시
- 사용자 입력이 감지되면 즉시 해제
- 화면 모드: 작업영역(workarea) 또는 전체화면(full)

## 5.4 안내 팝업(Notice)

- 텍스트/폰트/강조색/이미지/윈도우 크기 커스터마이징
- 미리보기 다이얼로그로 즉시 확인 가능
- 운영 정책 문구(전체화면 해제/종료 안내 등) 반영 가능

---

## 6. 관리자 비밀번호

- 설정 접근은 비밀번호 기반으로 보호됩니다.
- 초기 비밀번호 정책(기본값)은 운영 환경에서 즉시 변경을 권장합니다.
- 비밀번호는 해시+salt 형태로 저장되어 평문 노출을 줄입니다.

---

## 7. 로그/문제해결

로그 파일:
- `C:\AutoWake\autowake.log`

문제별 점검:

1. 브라우저가 실행되지 않음
   - Chrome 설치 여부/경로 확인
2. 세이버가 안 뜸
   - 유휴 임계값, 활성화 토글 확인
3. 안내 팝업이 안 나옴
   - Notice 활성화/반복 주기/Dismiss 상태 확인
4. 오디오가 자주 꺼짐
   - 재실행 쿨다운·반복 모드 조정, PWA 대신 Chrome 모드 사용

---

## 8. 운영 권장값(초기)

- Poll: 0.5s
- Saver 유휴 표시: 1200s(20분)
- 대상 재실행 쿨다운: 600s
- 오디오 재실행 쿨다운: 180s
- Notice 반복: 30분(필요 시)

운영 초기에 너무 공격적인 재실행(짧은 쿨다운)을 쓰면 사용자 경험이 나빠질 수 있으므로 점진 조정하세요.

---

## 9. EXE 배포 후 현장 운영 절차(권장)

1. 대상 PC에 `autowake_beta.exe` 배치
2. 1회 관리자 권한으로 실행해 기본 폴더 생성 확인
3. 설정값 입력 후 재시작
4. 30~60분 현장 관찰(브라우저/세이버/팝업 동작)
5. 이상 없으면 시작프로그램/작업스케줄러에 등록
